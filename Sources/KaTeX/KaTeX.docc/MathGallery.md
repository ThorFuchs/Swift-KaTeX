# Formula gallery

Explore examples rendered by Swift-KaTeX's SwiftUI components.

These images are captured from the [KaTeX Gallery](https://github.com/ThorFuchs/Swift-KaTeX/tree/main/Examples/KaTeXGallery)
example package. Each card shows the TeX payload below its rendered result.
The editable `.tex` files and the screenshot generator are in that package.
The gallery renders with a shared ``KaTeXRenderer`` in a fixed light appearance.
